==============
Parameter Maps
==============

Predefined :term:`Parameter Map Functions <Parameter Map Function>` convert
vectors of :term:`free parameters` to :term:`variational parameters`.
Register a map with :meth:`~quop_mpi.ansatz.set_parameter_map`.
